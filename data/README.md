# Historical datasets

Place frozen, point-in-time backtest inputs here. The sample configuration
expects `data/hyperliquid-daily.csv`; that file is intentionally not supplied
because current market-cap/OI snapshots must not be presented as history.

See `docs/backtesting.md` for the exact version-1 CSV schema and bias rules.
Large datasets and generated backtest results should normally stay outside Git.
